Wiring is optional

Ports and cables are hidden until you turn Wiring on (P). Without them, drop a component onto another to link them — a Person onto a board, a Board onto a Timeline, a Media onto a Media Grid or a screen — and the workspace tells you what the link means. A block can show its own ports with the eye icon in its panel header.

        Wiring rules

        1. Cables run left → right: from an OUT pin on the right of a node to an IN pin on the left of another.
        2. Colours must match: same type fits, any fits everything, number fits text; a person cable only fits a person slot. Lit pins fit; dimmed ones do not.
        3. Drag a pin to connect (either direction), grab a cable end to move it, drop it on empty space to disconnect.

        Build

        Add
        left toolbar: click a category, click a component (or drag it into the scene) · Shift+A search
        Move
        drag a block (Shift for height) · gizmo G, W/E/R
        Link
        drop a component onto another · or, with wiring on, drag from a pin to a lit pin
        Re-route
        grab a cable end and drop it on another pin · empty space disconnects · Esc puts it back
        Edit
        Ctrl+D duplicate · Del delete · Ctrl+Z / Ctrl+Shift+Z undo / redo
        Group
        Ctrl+G group · C collapse / expand · Ctrl+Shift+G ungroup
        Interact
        click / drag cards on a Kanban board · drop a card on a Person (or a Person on a card) to assign it · press Run on a Flow Terminal · click a checklist row · click a device screen or an Input face to fire events
        View
        P wiring · T theme · N panel · H help · Esc cancel
